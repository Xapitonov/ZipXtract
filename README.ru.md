ZipXtract — это полностью открытое приложение для Android, предназначенное для работы с широким спектром архивных форматов, включая:

* RAR (с поддержкой RAR5 и многотомных архивов)
* ZIP (включая защищенные паролем и разбитые архивы)
* TAR
* BZ2
* GZ
* 7z (с защитой паролем и поддержкой многотомных архивов)
* XZ
* JAR
* ...

## Особенности

### Извлечение:

* Поддержка различных форматов: RAR, ZIP, TAR, BZ2, GZ, 7z, XZ, JAR и т. д.
* Обработка зашифрованных ZIP и 7z файлов.
* Извлечение многотомных RAR архивов.
* Извлечение многотомных архивов.
* Извлечение разбитых ZIP файлов.

### Создание:

* Создание ZIP и 7z архивов с опциями шифрования.
* Создание разбитых ZIP архивов.

## Советы по использованию

Общие советы по извлечению архивов и созданию архивов:

* Длительное нажатие на файлы и папки или клик по иконкам файлов/папок для выбора их для архивирования.

* Нажмите на файл, чтобы открыть меню извлечения для выбора вариантов извлечения.

* Файлы, извлеченные с использованием меню "Открыть с помощью" операционной системы, по умолчанию сохраняются в Внутреннее накопители/ZipXtract. Измените это в настройках приложения.

* Местоположение по умолчанию для архивирования или извлечения архивов (в приложении) - родительская директория соответствующих файлов. Это можно изменить в настройках приложения.

## Разрешения приложения

Разрешение на чтение и запись накопителя (Android 10 и ниже) и разрешение на управление внешним накопителем (Android 11 и выше). Приложение не имеет разрешения на доступ в интернет. Подробнее - [Политика конфиденциальности](https://sites.google.com/view/privacy-policy-zipxtract/home)
